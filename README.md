# Cosmic Relics

A space-collecting game that runs in the browser. Open crates with published odds, register relics across 38 collections, chase variants and mutations, build a museum, fly ships to deep space and grow your fortune.

**Play:** https://milesddog0-cloud.github.io/cosmic-relics/

The whole game is a single file, `index.html`. Progress saves in your browser. Use Settings → Save data → Create save code to back it up or move it to another device.
